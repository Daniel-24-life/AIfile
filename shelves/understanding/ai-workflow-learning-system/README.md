# AI 工作流学习系统

[English](README.en.md) · [完整作品目录](../../../README.md)

将阅读、任务实践与复核沉淀为可再次使用的工作规则。读到的观点先进入任务，
检查实际结果，再决定是否保留。

## 方法与材料

工作循环为阅读、问题定义、工作流、证据、复核、复用。
知识、标准和战术分别对应事实理解、交付边界和任务顺序。
