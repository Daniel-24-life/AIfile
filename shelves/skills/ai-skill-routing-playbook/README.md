# AI 技能路由方法

[English](README.en.md) · [完整作品目录](../../../README.md)

先明确交付任务，再选择技能入口，分清生成、审阅、验证、格式处理和发布的职责。

## 方法与范围

每次选择前确认主要产物、任务类型、职责边界和完成检查。公开版整理路由原则、
职责地图与脱敏案例，不是私有工作环境的完整配置或脚本。
