# Taxonomy

## Content types

- showcase
- code skeleton
- playbook
- handbook
- understanding
- concept card
- article

## Lifecycle

- `draft`
- `review_ready`
- `published`
- `archived`

Lifecycle records the current state of an item. It does not contain a version
number.

## Repository release

The release field records the repository version that contains the item.
Current release: `v2.0`.
