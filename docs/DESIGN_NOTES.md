| 原始参考 | 可借鉴的组织方式 | 本作品集的选择 |

## 视觉系统

深蓝组织层级，青绿标示流程，暖色强调关键节点。封面为原创静态 SVG，分别适配
明暗主题。核心介绍保留为 Markdown 文本，图片失败时仍能阅读内容。
四个精选项目采用原生表格卡片，截图来自已公开的合成演示，BTC 使用原系统流程图。

## 阅读层级

个人主页给定位与四项精选；AIfile 组织十一项作品；独立仓库提供运行、结构、
代码阅读与测试。AgentPlatform 的停止状态放在显眼位置，不把局部技术验收描述为
产品目标已达成。不存在公开运行入口的项目不使用“在线体验”标签。

## 可维护性

登记表集中管理分类、精选排序和发布信息，手写介绍与生成导航分离。独立项目维护
自己的代码与 CI。旧入口继续指向新位置；旧源码在 v2.3 标签中保留。
GitHub 原生布局由平台提供，封面与内容不要求自定义 CSS 或页面脚本。
