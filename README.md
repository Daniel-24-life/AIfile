## 阅读与验证

先选一个业务问题，查看项目入口，再按兴趣进入架构、源码与证据。部分深度文档
保留英文，中文入口会注明语言。AgentPlatform 已停止开发，保留工程与产品复盘。

本仓库检查登记表、生成内容、本地链接、公开文本和仍在此维护的四个代码包。
独立项目的行为检查由各自 CI 执行。

```powershell
python -m pip install -r requirements-dev.txt
python scripts/verify_public_packages.py
```
