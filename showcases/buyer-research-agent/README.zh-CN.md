# 外贸买家研究 Agent

项目面向老板和销售，把“找企业”细化为“找需求、核企业、核联系、保留缺口”。
公开版提供一个能本地运行的离线工作台，使用四条虚构灯具记录。

## 从哪里看

先打开[运行说明](../../shelves/code/buyer-research-demo/README.md)，再看
[核心分类与队列代码](../../shelves/code/buyer-research-demo/core.py)。
工作台可以筛选需求类别、展开原文与日期、保存演示任务、暂停与恢复队列、
按顺序处理任务，并导出合成 JSON。

## 判断逻辑

明确需求需要企业身份、产品匹配、联系证据、原文核验和日期有效性。
项目公告只能作为采购机会。目录、缺失信息和过期需求进入待核验区。
采购权限始终保留未知，分类不会自动确认采购负责人。

离线样例的核验标志预先给定。公开版没有访问这些来源，也不会寻找真实企业。
产品输入只修改任务名称，不生成对应品类的新结果。

## 当前实现与真实结果

公开代码包含分类器、SQLite 演示队列、本地 API、页面和边界测试。
真实研究执行链、客户名单、联系方式、反馈与用量记录保留私有。
这里展示的是方法和工程结构，不声称形成询盘、订单或销售收益。
