# Publication scope

This public copy contains the existing reconstructed product UI, synthetic records,
a shared action policy, tests, reference notes and newly captured screenshots.

Employer and client relationships are anonymous. Original career files, raw
interviews, internal messages, private deployment identifiers, original research
reports, pilot feedback and real shipment data are excluded.

Integration labels describe mock sources. Displayed fees, confidence, health and
elapsed times are fixture values. Hardware support is a product adaptation
illustration, not evidence of installed devices. The UI simulates evidence
submission; it does not upload or validate an actual document.
