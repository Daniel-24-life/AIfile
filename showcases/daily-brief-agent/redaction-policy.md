# Redaction Policy

Real briefs, source lists, collection scripts, and personal judgments remain private.

## Included

The public folder includes:

- workflow structure
- system architecture
- evidence classes
- review gates
- fake sample items
- small code skeleton with fake data

## Outside The Public Folder

The following materials stay private:

- real daily briefs
- original rendered outputs
- real source URLs and watchlists
- daily generation scripts
- exact section prompts
- personal priority rules
- private interpretations
- browser profiles
- logs and run history
- continuous date records
- source ranking logic
- personal market or policy judgments
- unreleased notes or drafts
- credentials, cookies, tokens, and account sessions

## Generalization

Replacements used in this repository:

- real source lists into source classes
- real article titles into fake sample titles
- private judgment into review gates
- daily generated output into a public artifact model
- recurring scripts into a small review skeleton
