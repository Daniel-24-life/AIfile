# 每日简报审核 Agent

[English](README.en.md) · [完整作品目录](../../README.md)

为重复的信息整理工作建立来源分类、证据标记和引用检查，保留弱证据与缺失引用。

## 当前实现

公开版为重建说明、合成记录和引用审核骨架，不包含实时新闻采集、私有来源清单、
日报原文和生成脚本。代码验证来源与声明关系，不代表简报自动发布。
