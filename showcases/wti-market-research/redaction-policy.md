# Redaction Policy

The public case preserves the research question, method, selected results, and
source citations while removing the commissioning and application context.

## Included

- anonymized project description
- public data-source register
- research architecture and timing rules
- selected charts derived from public series
- frozen aggregate metrics and claim boundaries
- synthetic timing and review examples
- sanitized public DOCX and PDF reports
- runnable audit checks over synthetic records

## Outside the public folder

- organization and application names
- original directory names and local paths
- application notes, interview preparation, handoffs, and execution matrices
- raw XLS and CSV downloads
- cleaned tables, feature marts, predictions, and the SQLite database
- complete acquisition, cleaning, modeling, visualization, and report scripts
- caches, temporary renders, internal QA logs, and file hashes
- original DOCX and PDF files with application language or embedded metadata
- private thresholds, operating instructions, and any credentials

## Reconstruction choices

The report narrative was shortened and rewritten for a public portfolio. A
public Word copy keeps the original visual system while removing application
language and personal metadata; the public PDF is exported from that copy.
Charts were selected only when their labels, values, and captions matched the
frozen audit. The source files remain unchanged in the private workspace.
